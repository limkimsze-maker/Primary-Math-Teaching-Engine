Teacher guide: Mass Measurement Engine

Try your first activity

  1. Open Examples and click First steps for a simple 500 g scale, or choose a Scale capacities starting point.
  2. In Setup, choose what pupils will do: read a scale, move the pointer, find a difference, or practise a mixture.
  3. Choose the Scale unit, capacity in Setup. Open the Scale tab for the smallest interval, spacing of numbered marks and interval support. The large g or kg inside the dial tells pupils what its numbers mean. Numbered marks use whole numbers; smaller intervals on kg scales are stated in grams.
  4. Choose Pupil answer format: g, kg and g, or Pupil chooses g or kg and g. In the last option, pupils use Answer in above their answer boxes to switch formats. This applies to typed answers; pointer activities use the dial instead.
  5. For extra support, show the interval value, leave visual hints available and start with 5 questions. After changing settings, click Generate activity.
  6. Click Pupil view to teach or practise. Pupils click Check answer, retry if needed, and click Next question after a correct answer. Help me offers up to three hints. Click Teacher view to return to the builder.

What to teach

The engine uses an original circular diagram. No textbook photographs are included. Zero stays at the top, and the pointer makes one complete clockwise turn.

  • Find one interval. From 2 kg to 3 kg, 10 equal spaces mean each space is 100 g. Count spaces, not marks.
  • Read clockwise. Zero is at the top. One complete turn equals the capacity shown inside the dial. Generated questions stay below this capacity so zero and a full turn are not confused.
  • Match the answer unit. 2500 g = 2 kg 500 g. For a mixed-unit answer below 1 kg, use 0 in the kg box; for an exact number of kilograms, use 0 in the g box. The grams part must be 0–999.
  • Compare and order masses. Compare two readings to identify the heavier object. For ordering, read A, B and C and arrange them from lightest to heaviest. For difference questions, subtract the lighter mass from the heavier mass.

A clear classroom display: Setup, Scale and Examples are separate tabs so the builder stays compact. Pupil view gives the activity more room. The diagram stays in its own area, with answer controls kept beside or below it. Generate activity stays visible at the bottom of the builder. Pupil view applies any changed settings; if settings are unchanged, it keeps the current practice session. Feedback and hints use a separate area so the activity does not move when help appears. On shorter or smaller screens, or with enlarged text, scrolling remains available. The teacher guide opens over the activity; use Close or the Escape key to return.

What does “Download activity” save?

It saves your current settings, but it does not freeze the questions shown on screen.

Think of this as Download configured engine: a copy ready to use with the settings you chose.

It makes an HTML copy of this engine with your current settings. Open the file in a browser: it starts in Pupil view and works without internet. It does not freeze the questions currently on screen.

For example, choose a 5 kg scale, 100 g intervals and 8 questions. The file keeps those settings and generates fresh random questions each time it opens or restarts. Pupils opening the same file may get different questions.

  • Download again with the same settings: the same type of activity; the exact questions can differ.
  • Change settings, then download: the new file uses the changed settings.
  • The online engine is updated: older downloaded files stay unchanged. Download a new copy to get the latest improvements.

Share the HTML file with pupils for practice. Each downloaded copy also includes this teacher guide.

Save and load settings: Save settings downloads only the setup as a JSON file. Load settings restores that setup in the engine. The JSON file is not a runnable activity and does not include pupil results.

Use the summary: At the end, look at first-try answers, retries and hints used. Use these to plan follow-up teaching. The summary covers this session only; it is not a saved class report or a mastery grade.
