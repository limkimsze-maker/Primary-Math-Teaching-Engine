Teacher guide: Length Measurement Engine

Try your first activity

  1. Open Examples and click First steps for a simple centimetre ruler with whole-number intervals.
  2. In Setup, choose what pupils will do: measure a line, read a ruler mark, draw a given length, or practise a mixture.
  3. Choose the Ruler unit, where the ruler ends in Setup, then choose the Smallest interval in the Ruler tab. Begin with 1 cm intervals; use smaller intervals when pupils are ready.
  4. For measuring or drawing, choose whether the line starts at zero, away from zero, or a mixture. This setting does not apply to reading a single ruler mark.
  5. Leave visual hints available and start with 5 questions. After changing settings, click Generate activity, then Pupil view.
  6. Pupils type a number and click Check answer. For drawing, they drag the end of the line or use the slider, +/− buttons or arrow keys. They can retry, use Help me for up to three hints, then continue with Next question. Click Teacher view to return to settings.

What to teach

  • Read the intervals. Each space has the same value. Count spaces, not marks. If an interval is 0.5 cm, two spaces make 1 cm.
  • Measure between the ends. A line from 3 cm to 9 cm is 9 − 3 = 6 cm long. The end reading alone is not the length.
  • Draw from the start. To draw 5 cm from the 2 cm mark, put the end at 7 cm: 2 + 5 = 7.
  • Compare and order lengths. Align the starting points first. The line that reaches farther is longer. For three lengths, compare their end points and order them from shortest to longest.
  • Use the displayed unit. Pupils give their answer in the unit beside the answer box. This on-screen ruler is not actual size; use a real ruler for physical objects. On a small screen, a fine scale may need sideways scrolling.

A clear classroom display: Setup, Ruler and Examples are separate tabs so the builder stays compact. Pupil view gives the activity more room. The diagram stays in its own area, with answer controls kept beside or below it. Generate activity stays visible at the bottom of the builder. Pupil view applies any changed settings; if settings are unchanged, it keeps the current practice session. Feedback and hints use a separate area so the activity does not move when help appears. On shorter or smaller screens, or with enlarged text, scrolling remains available. The teacher guide opens over the activity; use Close or the Escape key to return.

What does “Download activity” save?

It saves your current settings, but it does not freeze the questions shown on screen.

Think of this as Download configured engine: a copy ready to use with the settings you chose.

It makes an HTML copy of this engine with your current settings. Open the file in a browser: it starts in Pupil view and works without internet. It does not freeze the questions currently on screen.

For example, choose a 15 cm ruler, 1 cm intervals and 8 questions. The file keeps those settings and generates fresh random questions each time it opens or restarts. Pupils opening the same file may get different questions.

  • Download again with the same settings: the same type of activity; the exact questions can differ.
  • Change settings, then download: the new file uses the changed settings.
  • The online engine is updated: older downloaded files stay unchanged. Download a new copy to get the latest improvements.

Share the HTML file with pupils for practice. Each downloaded copy also includes this teacher guide.

Save and load settings: Save settings downloads only the setup as a JSON file. Load settings restores that setup in the engine. The JSON file is not a runnable activity and does not include pupil results.

Use the summary: At the end, look at first-try answers, retries and hints used. Use these to plan follow-up teaching. The summary covers this session only; it is not a saved class report or a mastery grade.
