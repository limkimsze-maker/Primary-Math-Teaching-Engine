Using P1 to P3 Math Teaching Engine

Choose an engine

Select a topic tab on the left. The chosen engine opens immediately in the workspace. Use its teacher settings to choose the grade, task, values and number of questions, then press Generate activity. Measurement conversion is a dedicated P3 engine covering km ↔ m, m ↔ cm, kg ↔ g and ℓ ↔ mℓ with progressive Easy → Guided → Independent support. Comparing & ordering has a dedicated P1–P4 activity menu. Times Table Builder brings in the original Build Up, Take Away 1 Group, Subtracting Groups, Bridge Facts and Random Mix modes with slow group animations. P3 Sum & Difference Model uses a child-friendly staged flow: read the story, choose the model, build the model, then build and solve the equation. Mental sum groups its P3 lessons and quizzes by addition and subtraction strategy. P3 More Word Problems opens the original Monster Quest reference directly, preserving its diagrams, question flow and teaching steps exactly.

Display it clearly

Inside an engine, choose Pupil view. The Studio automatically hides its menus and uses the full available screen for teaching. A small Teacher view button remains at the top right so you can return to the settings. In Fractions, Previous, Next step, the answer, Check and Next question stay in one fixed control dock so the model remains large and the mouse targets do not move.

Download activity

A downloaded activity is a complete interactive HTML file using the settings currently shown. Fixed numbers reopen with the same example. Random practice keeps the chosen settings but generates fresh questions. Old downloads do not update automatically, so download again after website improvements.

Classroom use

Pause before each revealed step. Ask pupils what will move, what will be exchanged and what digit should be written. The toolkit supports teaching and discussion; its session summary is not a mastery grade or class report.
